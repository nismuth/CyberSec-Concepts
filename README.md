# CyberSec-Concepts
Tools commonly found in cybersecurity. Know what they look like to protect yourself.

klog.py - keylogging program similar to ones found in parental guidance software or spyware

executable_finder.py - scans a file directory and its subdirectories recursively for .exe files (file types often associated with malware)

port_scanner.py - takes a target IP or domain and provides open ports in a range of specific TCP (Transmission Control Protocol) ports
